# Missão Aquário Digital - Ecossistema Core

Sistema de monitoramento e garantia da qualidade da água para aquários digitais.

## Ambientes do Ecossistema
* **main**: Ambiente de Produção (código estável e final).
* **stage**: Ambiente de Homologação/Testes.
* **develop**: Ambiente de Desenvolvimento contínuo.
